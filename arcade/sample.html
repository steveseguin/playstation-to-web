Try a compiler sample

Use GRIDFALL’s single-map PS1 port to try the compiler with a complete, freely available game. The package includes the native PS1 executable, disc image, symbols, source, assets, and browser player.

Download the sample · Play the precompiled version · Game source

Recompile the PS1 executable

On Linux or WSL, install Python 3.10+, Git, Rust 1.94.1, and Clang with the WebAssembly target and wasm-ld. Extract the download and run:

cd gridfall-ps1
bash tools/build-web.sh
python3 tools/serve.py

Open localhost:8196. The build downloads a pinned psxw revision, translates the bundled PS1 machine code, then links it into WebAssembly. No BIOS or commercial game files are needed.

Change the source

To rebuild the PS1 game first, also install CMake, Make, curl, and unzip, then run bash tools/build.sh before the web build. The native build downloads a pinned PSn00bSDK toolchain. Load build/gridfall.cue with gridfall.bin beside it to play the PS1 version.

In a PlayStation to Web checkout, bash scripts/build-gridfall.sh extracts and recompiles the same sample; add --from-source to rebuild its PS1 executable too.

While playing in the arcade, open Apply mod to change movement speed or palette without restarting. The standalone player has the same controls in its live mods panel.
